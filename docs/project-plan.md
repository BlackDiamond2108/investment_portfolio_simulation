Назначение: локальная экономическая игра по документу
/home/xd/Downloads/Система_управления_инвестиционным_портфелем.docx.
Игрок управляет фондом в течение 12..30 месяцев; доступны RUB/валютные вклады,
акции, государственные облигации и металлы. Можно открыть несколько вложений одного вида.
Каждый месяц: доход -> налог -> поступления -> возврат средств -> реструктуризация.
Доход и налог автоматические, реструктуризация ручная, потоки ручные либо автоматические.
Настраиваются капитал, M, налог, начальные вложения и случайные изменения рынка.
В любой момент видны позиции, общий капитал, доход по статьям и условия рынка.
Итоги включают прибыль, доходность, поступления и возврат паёв.
Сохранение/seed — удобные дополнения; график, сеть, сервер и база данных не нужны на старте.

Связи:
main -> MainWindow -> Simulation -> Portfolio.
MainWindow -> GameStorage -> GameState.
Все классы используют структуры GameTypes.h. Portfolio и Simulation не зависят от Qt.
Simulation владеет единственным состоянием партии и генератором. Portfolio работает
с переданными данными. MainWindow владеет Simulation и показывает её состояние.
GameStorage только читает/пишет данные: загрузку принимает Simulation.restoreState.

Пример покупки:
поля формы -> MainWindow.collectTradeRequest -> Simulation.previewTrade -> Portfolio;
подтверждение -> Simulation.trade -> проверка фазы/долгов -> Portfolio.executeTrade ->
оплата обязательств -> MainWindow.refreshView. Предпросмотр не меняет состояние.

Пример месяца:
кнопка -> Simulation.nextMonth -> новый рынок -> Portfolio.accrueAndRedeem ->
подсчёт прибыли/налога -> AwaitingFlows. Окно показывает предложение потоков.
Подтверждение -> applyFlows -> Restructuring. Игрок выполняет сделки.
finishMonth записывает отчёт и разрешает следующий месяц или завершает партию.
Переходы атомарны; повторная команда отвергается независимо от состояния кнопок.

Сохранение:
MainWindow -> Simulation.exportState -> GameStorage.save.
Загрузка: GameStorage.load -> временный GameState -> Simulation.restoreState -> refreshView.
Ошибка не заменяет текущую партию. Все промежуточные фазы и RNG сохраняются.

   Проверить ручной пример начисления и сохранение баланса при сделках.
3. Simulation: сначала фиксированный рынок/ручные потоки, потом случайный рынок,

4. Заполнить вкладки MainWindow и связать с расчётами. Пройти игру на 12 месяцев.
5. GameStorage: сохранить/загрузить каждую фазу, сверить продолжение партии.
6. Итоговые показатели, граничные случаи, ctest и ручная проверка всех требований.

Проверочный сценарий:

сохранить/загрузить; завершить M месяцев. Повторить в автоматическом режиме.
Сверить доходы по позициям с общей прибылью, отделить приток денег от доходности.
